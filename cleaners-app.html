Cleaners App

A complete service tracking solution for cleaning professionals with real-time task management

Project Overview

The Cleaners App is a service-tracking application designed for real-time task management. It enables cleaning professionals to receive, update, and complete service requests efficiently.

Built with modern Android technologies, the app features real-time notifications, task assignment, progress tracking, and seamless communication between clients and service providers.

Key Features

  • Real-time task tracking — Live updates on service status
  • Image upload & storage — Before/after cleaning photos via Supabase
  • Push notifications — Instant alerts for new assignments
  • Secure authentication — Firebase Auth with role-based access
  • Service history — Complete log of completed tasks
