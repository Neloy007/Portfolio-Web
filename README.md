## 🎨 Overview

This is my **personal developer portfolio** – a modern, premium, and fully responsive website designed to showcase my work as an **Android Developer**. The design features a **dark glassmorphism UI** with a distinctive **Kotlin-inspired purple theme**, smooth animations, and a focus on visual hierarchy.

The goal of this portfolio is to present my skills, projects, and experience in a visually striking yet professional manner, making a strong first impression on recruiters and collaborators.

## ✨ Key Features

- **💜 Premium Glassmorphism Design** – Modern frosted-glass effect with backdrop blur and subtle purple borders.
- **🎯 Clear Visual Hierarchy** – Prominent hero section with a gradient name, role, and call-to-action.
- **📱 Fully Responsive** – Optimized for desktop, tablet, and mobile devices with a collapsible navigation menu.
- **⚡ Smooth Animations** – Scroll-triggered reveals, floating profile image, hover effects on cards and buttons.
- **📊 Dynamic Statistics** – Animated counters that update with live random values for engagement.
- **🛠️ Interactive Skills Section** – Animated skill bars that fill on scroll.
- **🎨 Kotlin Purple Branding** – Cohesive purple color palette throughout all UI components.
- **🔗 Project Detail Pages** – Individual pages for each project with expanded information, tech stacks, and architecture diagrams.
- **🗺️ Integrated Location Map** – Embedded Google Map showing my location.
