Exam Taker Ecosystem

A complete exam management solution with student mobile app and admin web dashboard

Project Overview

The Exam Taker Ecosystem was developed to bridge the gap between students and examiners. It features a high-performance Android application built with Jetpack Compose and a powerful Web Admin Dashboard for real-time management.

This dual-platform system allows students to take timed quizzes, view results instantly, while administrators can create, manage, and analyze exams with real-time analytics.

Key Features

  • Role-based authentication — Secure login for students and admins
  • Timed quizzes — Real-time countdown with auto-submit
  • Automated grading — Instant feedback and result calculation
  • Real-time sync — Firebase-powered question bank updates
  • Admin dashboard — Analytics, question management, and reporting
